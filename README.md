# ScriptForge — AI Video Generator

Вводи тему → получай готовое вертикальное видео для TikTok/Reels/Shorts.

## Как использовать
1. Введи тему
2. Выбери тон (Мистика / Наука / Шок / Мотивация)
3. Нажми "Создать видео"
4. Скачай готовый MP4

## Секреты
Установи переменную окружения `PEXELS_API_KEY` в настройках Space для реального видеофутажа.
